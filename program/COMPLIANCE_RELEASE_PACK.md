# 合规与发布材料 V1

## 首发版必须覆盖的治理项

1. 内容版权边界
2. 未成年人场景边界
3. 用户隐私与行为数据边界
4. 宿主集成与权限边界
5. 发布审核与回滚边界

## 内容版权规则

- 来源不清的教材、题目、文献不得进入公开发布目录
- `content/review/approved/` 仅表示内容审核通过，不等于版权合规已完成
- 发布清单只能包含明确来源和使用边界的资产

## 未成年人规则

- K12 内容必须避免诱导性、成人化和越界研究材料
- 反馈、搜索和行为数据不得用于未成年人画像扩张
- 练习和考试页面不显示宿主无授权的外部分享能力

## 隐私规则

- BFF 当前只持久化用户笔记、复习、反馈、搜索、学习事件、练习结果、考试结果
- 不写入手机号、支付、真实姓名等平台主身份数据
- 宿主 token 不在 `runtime/` 落库；只与 registry 中的 hash 做校验

## 宿主集成规则

- 允许宿主通过 query、window、bridge、postMessage 注入上下文
- 所有用户态接口优先读取 `x-host-user-id`
- 只暴露必要事件，不暴露完整内部状态树

## 发布门

- 内容已审核
- 发布清单已生成
- 回滚路径明确
- WebView 兼容回归已执行
- 高风险宿主能力有人工放行记录

## 当前缺口

- 版权来源台账仍需按课程和题库扩展
- 当前宿主鉴权是本地 registry 版，尚未接入平台正式鉴权服务
- 未成年人内容策略目前是规范层，尚未做自动拦截
