# Trace Grading 规则 V1

## 目标

对首发版关键工作流进行轨迹级评分，不只看最终页面是否能打开。

## 评分维度

| 维度 | 说明 | 分值 |
| --- | --- | --- |
| 输入完整性 | 是否读取了正确上下文、课程和用户 | 20 |
| 路由正确性 | 是否进入正确页面和正确内容 ID | 20 |
| 数据回流 | 是否写入笔记/行为/结果/反馈 | 20 |
| 宿主输出 | 是否向宿主发出正确事件 | 20 |
| 错误处理 | 失败时是否可追踪和可回滚 | 20 |

## 首批必评分流程

1. 宿主上下文注入 -> 首页加载 -> 报告页拉取
2. 精读进入 -> lesson_started 输出 -> 学习行为写入
3. 练习自评 -> 结果写入 -> 报告页出现结果
4. 试卷提交 -> checkpoint_saved -> 报告汇总
5. 审核工作台审批 -> 审核状态变更

## 放行规则

- 80 分以下不得视为放行
- 宿主输出或数据回流任一维度为 0 分，直接阻断
