# Stage A A/B 与对照实验 V1

## 实验 1：精读导引是否提升完成度

- 对照组：纯段落阅读
- 实验组：时间线 + 高亮 + 重点提示
- 核心指标：
  - 章节完成率
  - 首屏停留时间
  - 章节后练习正确率

## 实验 2：结构图是否提升概念迁移

- 对照组：文字说明
- 实验组：节点图 + 关系链
- 核心指标：
  - 概念题正确率
  - 迁移题正确率
  - 概念页停留时间

## 实验 3：结果级反馈是否提升复习命中率

- 对照组：仅展示分数
- 实验组：展示薄弱点 + 推荐下一步
- 核心指标：
  - 推荐练习点击率
  - 二次练习正确率
  - 复习完成率
