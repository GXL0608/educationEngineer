# 设计系统 V1

## 设计方向

首发版采用“温暖纸面 + 结构化仪表”的混合风格。阅读感优先，避免后台系统感和陈旧教育软件感。

## 核心 Token

### 字体

- 标题：`Manrope`
- 正文：`Noto Sans SC`

### 颜色

- 主背景：`#f4eee4`
- 强背景：`rgba(255, 255, 255, 0.94)`
- 弱背景：`rgba(241, 234, 222, 0.82)`
- 主文本：`#1f2430`
- 次文本：`#5d6778`
- 主强调：`#b1532f`
- 辅强调：`#1f6e78`

### 间距与圆角

- 页面间距：`1rem / 1.5rem / 2rem`
- 卡片圆角：`1rem - 1.6rem`
- 胶囊按钮：`999px`

### 阴影与动效

- 主阴影：`0 22px 60px rgba(39, 36, 26, 0.12)`
- 轻动效：`160ms ease`

## 页面结构规则

- 左侧固定为模块导航和宿主调试信息。
- 右侧主区只承载当前任务，不混入过多全局信息。
- Hero 区负责价值主张，Panel 区负责单任务执行。

## 页面 IA 原则

- 首页：入口、总览、当前范围说明
- 导航页：学段到课程的层级下钻
- 课程页：课程简介、章节树、学习入口
- 章节页：章节级切换和四种主动作入口
- 学习页：时间线 + 文本
- 概念页：节点 + 关系链
- 练习页：题目 + 自评 + 结果写入
- 试卷页：章节块 + 成绩录入 + 薄弱节标记
- 报告页：系统汇总 + 用户结果汇总

## 组件层规则

- `PanelShell`：标准内容容器
- `MetricCard`：指标信息卡
- `QuestionCard`：题目展示和题后动作
- `FocusTextPanel`：分段阅读器
- `KnowledgeStrip`：节点与链条
- `LessonTimeline`：节奏轴

## 响应式规则

- `980px` 以下切单栏
- `640px` 以下减少边距，顶部栏纵向排布
- 移动端不允许仅靠缩放压缩内容
