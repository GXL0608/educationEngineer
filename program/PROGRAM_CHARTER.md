# 项目章程

## 项目名称

教育工程 Web 模块

## 项目使命

构建一个面向真实用户发布、可嵌入外部平台、覆盖 K12 到博士层级内容扩张的认知增强型教育工程 Web 系统。

## 当前首发目标

首发版必须同时打通：

- 教程化精读能力
- 概念结构化讲解能力
- 基础练习与基础试卷能力
- 文献精读能力
- 错题复盘与学习报告能力
- 宿主平台嵌入能力

## 不做事项

- 不自建账号、支付和原生壳子
- 不做脱离内容模型的随机功能堆叠
- 不做无验证直接发布
- 不做无任务锁的多智能体并行写入

## 成功标准

- Web 模块可以真实运行并被宿主平台嵌入
- 核心页面可用且设计达标
- 内容工厂、题库系统和多智能体交付链路成立
