# 路线图

## Stage A：首发版（第 1-24 周）

- 建课程宇宙母模型
- 建页面体系和设计系统
- 建内容解析、脚本生成、组件库
- 建练习、试卷、错题、报告基础能力
- 建可嵌入 Web 模块
- 建多智能体无冲突执行体系

## Stage B：K12 核心扩张（第 6-12 个月）

- 扩张 K12 主科目录
- 建教材版本映射
- 建章节题、专题题、阶段测

## Stage C：大学核心扩张（第 12-18 个月）

- 扩张公共基础课与专业核心课
- 建 syllabus 与讲义映射

## Stage D：研究生扩张（第 18-24 个月）

- 扩张硕士与博士课程
- 升级文献工作台为研究工作台

## Stage E：全量覆盖（第 24-36 个月）

- 扩张到全学段全学科课程宇宙
- 管理多教材版本、多考纲版本和多试卷体系
