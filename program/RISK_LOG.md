# 风险日志

## 当前主要风险

1. 仓库起点为空仓，基础设施需要从零搭建。
2. 总目标极大，必须严格区分首发版和全量版。
3. 多智能体并行若无任务锁，极易互相覆盖。
4. WebView 兼容性必须从一开始纳入回归。
5. 内容扩张若无统一模型，后续会失控。
6. 宿主上下文来源多样，若没有统一 contract，用户态数据可能写错桶。
7. benchmark、A/B、trace 若只停留在文档，不会形成真实放行能力。

## 当前应对

- 已建立工作板与任务锁工具
- 已建立 program 标准件
- 代码骨架按应用边界拆分
- 已建立宿主嵌入协议、回滚方案、benchmark 任务集和 trace grading 规则
